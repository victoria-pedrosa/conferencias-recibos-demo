# Conferencias Recibos

> Projeto de portfólio de **Victória Pedrosa** (Automação, Processos e Dados). Automação desenvolvida para um escritório de contabilidade; **esta é uma versão com dados fictícios** — nomes, CNPJs, e-mails e IDs internos foram substituídos.

## Problema de negócio
Conferir se cada empresa tem o recibo de entrega da DCTFWeb, ECD e EFD exigia abrir pastas uma a uma.

## Antes x depois
| | Antes | Depois |
|---|---|---|
| Como é feito | Conferência manual nas pastas do Drive. | Scripts localizam os recibos nas pastas e marcam o status na planilha. |

## Ganho
- Entregas comprovadas e pendências visíveis.

## Tecnologias
Google Apps Script, Google Drive, Google Sheets

## Arquivos
- `ConferenciaECD.gs`
- `ConferenciaReciboDCTFWeb.gs`
- `ConferenciaReciboEFD.gs`

## Como usar
Crie um projeto no Google Apps Script, copie os arquivos `.gs`/`.html` e configure as Propriedades do script indicadas no código.
